# HUMANE-SE Thesis Summary

## Title

HUMANE-SE: Introducing Human-Centric Software Engineering Jobs and Learning Pathways in the Digitalized Era

---

## Abstract

HUMANE-SE is a research-oriented framework that investigates the coexistence of technical and human-centric skills in modern Software Engineering labor markets.

The framework introduces the concept of "humics" — uniquely human skills that remain resistant to automation and continue to play a critical role in AI-driven development environments.

Using approximately 15,000 Software Engineering job postings collected between 2020 and 2024, the framework combines:

- ESCO-based skill extraction
- NLP and semantic similarity techniques
- Co-occurrence network analysis
- Humics Hub detection
- AI-assisted recommendation generation

The analysis revealed that communication, adaptability, collaboration, empathy, and problem-solving remain highly demanded competencies despite increasing automation in Software Engineering workflows.

Additionally, the framework identified hybrid skill clusters where human-centric and technical competencies coexist within emerging Software Engineering occupations.
