# HUMANE-SE Results Overview

## Overview

The HUMANE-SE framework was applied to approximately 15,000 Software Engineering job postings collected between 2020 and 2024.

The analysis focused on identifying human-centric skills ("humics"), their relationships with technical competencies, and the emergence of hybrid skill profiles within modern Software Engineering roles.

---

## Key Findings

### Most Frequent Humics Skills

The analysis revealed that communication was the most frequently requested humics skill across Software Engineering job postings.

Other highly frequent humics included:

- Professional development
- Collaboration
- Technical problem-solving
- Adaptability
- Empathy
- Decision-making
- Team building

The results demonstrate that human-centric skills remain essential despite increasing automation in Software Engineering environments.

---

## Humics Hubs

Network analysis revealed the existence of Humics Hubs — clusters of co-occurring technical and human-centric skills.

Examples include:

| Humics Skill | Related Technical Skills | Hybrid Profile |
|---|---|---|
| Communication | Presentation software, collaboration tools | Digital Communication Proficiency |
| Problem-solving | Research, project management | Creative and Technical Problem Solving |
| Adaptability | Agile workflows, cloud systems | Adaptive Technical Collaboration |

These hybrid clusters indicate that employers increasingly seek professionals capable of combining technical expertise with uniquely human capabilities.

---

## Occupation Similarity Analysis

Occupation similarity networks identified several emerging Software Engineering roles strongly associated with hybrid skill profiles.

Examples include:

- Blockchain Developer
- Mobile Application Developer
- Embedded Systems Software Developer
- ICT Application Developer

The occupation ego networks revealed how technical specialization increasingly overlaps with human-centric competencies.

---

## AI-assisted Recommendation Generation

The framework generated draft job role and learning pathway recommendations using LLM-assisted prompting workflows combined with expert validation.

Example recommendation:

### Hybrid Role

Agile Project Facilitator

### Learning Outcome

Demonstrate the ability to adapt workflows in agile cloud-based environments while maintaining collaboration and operational efficiency.

---

## Overall Conclusion

The results suggest that the future of Software Engineering is increasingly defined by hybrid skill profiles combining:

- Technical expertise
- Adaptability
- Communication
- Collaboration
- Ethical reasoning
- Continuous learning

The HUMANE-SE framework demonstrates how human-centric competencies remain strategically important in AI-driven labor markets.
